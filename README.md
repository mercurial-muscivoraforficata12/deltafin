## 🛠️ Troubleshooting Issues

If you encounter problems, review this list of common solutions:

* **The server does not start.** Ensure no other programs use port 8000. Close other local server tools before you launch deltafin.
* **The model responds slowly.** Check your task manager to see if other programs consume your memory or graphics processor. Close background tabs in your web browser to free up resources.
* **The program crashes.** Check that you installed the latest drivers for your graphics card. Outdated drivers often cause problems with artificial intelligence applications.
* **The interface does not connect.** Verify that your settings point to "localhost" or your computer's local IP address.
